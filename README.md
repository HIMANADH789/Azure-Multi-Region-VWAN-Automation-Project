# 🌐 Azure Multi-Region VWAN & VPN Automation Project

## Project Description
This project demonstrates the **end-to-end setup of a multi-region Azure infrastructure** with automation and secure networking practices. The main objectives include:

- Creating **Virtual Networks (VNets) and Subnets** across multiple regions.
- Deploying **Virtual Machines** in frontend, backend, and additional regions.
- Configuring **Network Security Groups (NSGs)** for secure traffic management.
- Setting up **Virtual WAN (VWAN) Hub** to connect multiple VNets in a hub-and-spoke topology.
- Implementing **Point-to-Site VPN** for secure remote access.
- Using **Azure Network Watcher** and dashboards for monitoring and metrics.
- Automating deployment using **Python Azure SDK** (ARM-based provisioning).

This setup simulates **enterprise-level cloud networking** and demonstrates practical cloud automation skills, ideal for cloud/networking internship interviews.

---

## Tech Stack
- **Cloud Provider:** Microsoft Azure  
- **Networking:** Virtual Networks (VNets), Subnets, NSGs, Load Balancers, Virtual WAN, VPN Gateway  
- **Automation / Scripting:** Python, Azure SDK (ResourceManagementClient, NetworkManagementClient, ComputeManagementClient)  
- **Monitoring:** Azure Network Watcher, Flow Logs, Traffic Analytics, Dashboards  
- **Architecture Visualization:** PlantUML / draw.io  
- **Other Tools:** Git/GitHub for version control, Bash for environment setup
